# Content handling

このプロジェクトはPrivateリポジトリでの個人利用を前提とします。

## Gitに保持するもの

- 選手プロフィール
- 成績
- 紹介文
- 応援歌の使用時期・参考リンク
- 個人利用用の応援歌歌詞

応援歌歌詞は各選手JSONの `cheers.variants[].lyrics` に直接保持できます。

```json
{
  "cheers": {
    "variants": [
      {
        "period": "2014–2021",
        "name": "ロッテ応援歌",
        "lyrics": "個人利用用の歌詞"
      }
    ]
  }
}
```

## Gitに入れないもの

- 第三者が権利を持つ写真ファイルのコピー
- 動画・音源ファイル
- 生成済みの `dist/` 成果物

これらは必要に応じて `local-assets/` などで管理します。

## Public化する場合

このリポジトリを将来Publicに変更する場合は、応援歌歌詞・第三者素材などを公開してよいか改めて確認し、必要に応じて削除・差し替えを行います。
